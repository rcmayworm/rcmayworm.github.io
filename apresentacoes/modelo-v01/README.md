# Modelo de apresentações científicas — prévia v0.1

Apresentação demonstrativa em Quarto + Reveal.js. Os exemplos são sintéticos.
O tema SCSS e a composição são originais; a apresentação do professor Jodavid Ferreira serviu apenas como referência funcional e estética.

## Prévia pública

https://rcmayworm.github.io/previas/modelo-apresentacoes-v01/

A prévia não consta no catálogo oficial de apresentações, pois ainda está em revisão visual.

## Editar e renderizar

Dentro desta pasta execute `quarto render template.qmd`. Para mostrar os slides em outro computador, copie o HTML autocontido gerado. As notas do apresentador são acessíveis pela tecla S e o menu lateral pela tecla M.

O código do modelo ainda não possui uma licença de distribuição definida.
